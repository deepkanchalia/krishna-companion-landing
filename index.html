Set it up, no coding required

Five steps to your first darshan

About 10 minutes. Works on macOS. Every command has a Copy button, so you paste and press Return. You cannot break anything.

Install Node.js

Download the macOS Installer from nodejs.org (the LTS version) and click through it.

Why: it is the free engine the companion runs on.

Open the Terminal

Press ⌘ Space, type Terminal, press Return.

Set it up

Paste this block, press Return.

git clone https://github.com/deepkanchalia/krishna-companion.git
cd krishna-companion
npm install --ignore-scripts
mkdir -p ~/.local/bin
ln -s "$PWD/bin/krshna.js" ~/.local/bin/krshna
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
export PATH="$HOME/.local/bin:$PATH"

If it asks for “developer tools,” click Install and wait. That is Apple's git.

Make it live

krshna

First run downloads about 90 MB, then Kṛṣṇa appears on his own.

Enjoy, these are yours anytime

krshna now     # a verse right now
krshna pause   # quiet mode
krshna style cartoon   # change the figure

Or press ⌘ ⌥ K, or use the 🪶 menu-bar icon.

Fully private

No network calls. Verses ship inside the app; your place stays on your Mac.

Voice is optional

Off by default. Enable “Hare Kṛṣṇa” later with krshna voice on.

Easy to remove

Run krshna stop and delete the folder. Nothing left behind.
