# Krishna Companion Landing

A plain static landing page for the Krishna Companion, imported untouched from
the v24 claude.ai artifact prototype. It is a single `index.html` plus an
`/assets` directory, with no framework, bundler, or build step; it renders the
intro hands and dissolve, a cursor-lit drifting grid, six selectable figures, a
warrior darshan loop, WhatsApp CTAs, an install guide, and a sound-toggle stub.
See `AGENTS.md` / `CLAUDE.md` for the engineering guardrails.

## Local preview

```
python3 -m http.server
```

Then open the served address in a browser.
